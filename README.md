# Amoeba STB Monitor

ZTE B860H V1 Armbian OLED monitor project.

Build artifacts and installation instructions will be published through GitHub Actions after the kernel/DTB build is validated.

**Safety:** Do not connect the OLED or install a modified DTB until the physical board routing for GPIODV_24 (SDA) and GPIODV_25 (SCL), voltage levels, and recovery path are verified.
